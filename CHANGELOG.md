# Changelog

All notable changes to the `runtimeverify` project will be documented in this file.

## [0.1.0] - 2026-07-19
### Added
- **Core Verification Pipeline:** Streamingly converts telemetry events to taxonomic execution states.
- **Statistical Detectors:** First-order Markov chain matrices and sequential SPRT models.
- **Evaluation framework:** Confusion matrices, synthetic anomaly generators, and replay benchmark suites.
- **Command-line Interface:** Typer `verify` runner with dynamic entrypoint plugins.
- **REST API & Dashboard:** FastAPI endpoint server with a live dark-mode status panel.
- **Integrations:** Telemetry wrappers for LangGraph, PydanticAI, and CrewAI.
- **Enterprise SDK & Extension Stub:** VS Code side panel manifest and Cloud Client reporter.
