# Security Policy

We take security seriously. If you identify a security vulnerability in this verification framework, please report it responsibly to protect downstream agents.

## Reporting a Vulnerability

**Please do not open a public GitHub issue for security bugs.**

Instead, report vulnerabilities by emailing the core safety team at:
`agent-security@google.com` (or submit a report via the Google Bug Hunters portal).

Please include:
1. A descriptive summary of the potential vulnerability.
2. Step-by-step instructions or code to reproduce the exploit.
3. Your assessment of the impact (e.g. escaping the policy block, telemetry manipulation, sandbox escape).

We will acknowledge receipt within 48 hours and work with you to coordinate a disclosure schedule.
