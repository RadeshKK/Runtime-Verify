# Architecture Overview

This document describes the high-level architecture of the `runtimeverify` system.

## System Design
The system is designed to provide runtime verification of software properties.

## Components
- **Detector**: Monitors system state.
- **Policy Engine**: Evaluates states against defined policies.
- **Encoder**: Transforms raw system data into a verifiable format.
- **Telemetry**: Collects and exports verification metrics.
