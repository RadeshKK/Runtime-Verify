# Detector API

This document defines the mathematical foundations, core interfaces, and execution models of the statistical detectors in the `runtimeverify` framework.

---

## 🧮 Mathematical Foundations

The core task of a detector is to determine whether the sequence of encoded agent states $S = (s_1, s_2, \dots, s_t)$ is generated by a "normal" behavioral model ($H_0$) or an "abnormal/malfunctioning" model ($H_1$).

### 1. Markov Chain Modeling
Under a first-order Markov Chain model, the probability of transitioning to state $s_t$ depends only on the immediate prior state $s_{t-1}$:

$$P(S) = P(s_1) \prod_{i=2}^t P(s_i \mid s_{i-1})$$

During training on historical logs of "normal" agent runs, the system calculates a transition probability matrix $T$, where:

$$T_{i, j} = P(s_t = j \mid s_{t-1} = i)$$

Any transition with $T_{i,j} = 0$ (or below a tiny threshold $\epsilon$) represents an illegal or highly anomalous jump.

### 2. Sequential Probability Ratio Test (SPRT)
Rather than raising an alert on a single rare transition (which causes high false positive rates), `runtimeverify` employs **SPRT** (Sequential Probability Ratio Test) to evaluate cumulative evidence.

We set up two hypotheses:
- **$H_0$ (Normal):** The agent behavior matches the trained transition matrix $P(s_t \mid s_{t-1}; H_0)$.
- **$H_1$ (Drifted):** The transitions are drawn from an alternative distribution $P(s_t \mid s_{t-1}; H_1)$ (representing high-entropy, anomalous transitions).

The cumulative log-likelihood ratio $\Lambda_t$ is updated recursively with every state transition:

$$\Lambda_t = \Lambda_{t-1} + \ln \frac{P(s_t \mid s_{t-1}; H_1)}{P(s_t \mid s_{t-1}; H_0)}$$

We define false positive limit $\alpha$ and false negative limit $\beta$ to calculate thresholds:
- Upper threshold $B = \ln(\frac{1 - \beta}{\alpha})$
- Lower threshold $A = \ln(\frac{beta}{1 - \alpha})$

**Decision Rules:**
- **$\Lambda_t \ge B$:** Reject $H_0$ (Confirm anomaly/drift, trigger block/alert).
- **$\Lambda_t \le A$:** Accept $H_0$ (Reset $\Lambda_t$ to 0, normal run continues).
- **$A < \Lambda_t < B$:** Continue observing.

## 💻 Developer API: `BaseDetector`

All detectors implement the `BaseDetector` interface in [runtimeverify/detector/](file:///D:/runtime-verify/runtimeverify/detector/):

```python
from abc import ABC, abstractmethod
from typing import List, Dict, Any
from pydantic import BaseModel

class DetectorResult(BaseModel):
    """Result data structure for transition evaluation."""
    deviation_score: float         # Current statistic value (e.g. Lambda_t)
    decision: str                  # "NORMAL", "DRIFT", or "PENDING"
    evidence: Dict[str, Any]       # Supporting stats (e.g. p-value, transition probability)

class BaseDetector(ABC):
    """Abstract interface for statistical anomaly detection models."""

    @abstractmethod
    def train(self, trace_sequences: List[List[str]]) -> None:
        """
        Trains the behavior model using a collection of normal state sequences.
        
        Args:
            trace_sequences: A list of sequences of state strings.
        """
        pass

    @abstractmethod
    def update(self, current_state: str) -> DetectorResult:
        """
        Incorporate the latest state transition into the running statistical test.
        
        Args:
            current_state: The newly encoded state.
            
        Returns:
            A DetectorResult showing the current anomaly status.
        """
        pass

    @abstractmethod
    def reset(self) -> None:
        """Resets the running statistical state (e.g. clears Lambda_t to 0)."""
        pass
```

## 🚀 Built-in & Future Detectors

`runtimeverify` is designed to support a suite of classical statistical detectors:

| Detector | Status | Description |
| :--- | :--- | :--- |
| **`SPRTDetector`** | Core | Sequential Probability Ratio Test on Markov transition probability matrices. |
| **`HMMDetector`** | Planned | Hidden Markov Model for tracking unobserved latent states (e.g., agent "goals"). |
| **`CUSUMDetector`** | Planned | Cumulative Sum Control Chart for monitoring scalar metrics like latency or errors. |
| **`ChangePointDetector`** | Planned | Bayesian Online Change Point Detection for structural shifts in state sequence patterns. |
